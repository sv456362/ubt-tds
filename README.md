UBT-TDS — лёгкая TDS без базы данных и крона. Разливает трафик по офферам по весам, ведёт статистику по дням, отличает ботов от живых людей и помещается даже на бесплатный хостинг.

## ✨ Что умеет

- 🔀 **Ротация офферов по весам** — задал пропорции (70/30), трафик идёт сам
- 📊 **Статистика**: хиты, уники (cookie + IP), боты, рефереры, языки, устройства
- 📅 **График за 30 дней** с кликабельными днями — клик по цифре = полный лог за день
- 🏷️ **Метки источников** прямо в ссылке: `?tg`, `?vk`, `?google`
- 🤖 **Антибот**: явные подписи + «рецидивисты без cookie», живые браузеры не страдают
- 🔗 **Короткие ссылки** вида `домен.com/camp1`
- 🧙 **Мастер первого запуска**: сам генерирует логин, пароль и секретный адрес панели
- 🛡️ **Безопасность**: bcrypt, троттлинг перебора, CSRF, скрытая панель

## ⚡ Почему легче обычных TDS

| Типичная TDS | UBT-TDS |
|---|---|
| Требует MySQL | Без БД — обычные файлы |
| Нужен VPS от $5 | Живёт на фрихостинге |
| Крон для ротации логов | Ротация = удаление файла дня |
| Час установки с бубном | Залил файлы → мастер настройки |

Архитектура «один файл = один день»: статистика за день читает один маленький файл, график — кэш из 30 строк. Сервер не напрягается даже на тысячах кликов.

## 📦 Установка (5 минут)

1. Скачай архив кнопкой **Code → Download ZIP** (или в Releases, когда появится).
2. Залей все файлы в корень хостинга.
3. Открой `https://ваш-домен/admin.php` — поля уже заполнены `admin/admin`, жми «Войти».
4. Нажми «открыть мастер настройки»: он сам сгенерирует логин, пароль и имя панели. Скопируй данные, поставь галочку «я сохранил» и жми «Перейти в админку».
5. В админке нажми «Удалить tools/make_hash.php» — настройка завершена.
6. Создай кампанию, добавь офферы с весами, скопируй короткую ссылку — лей трафик!

Полное руководство «для самых маленьких» — в `README.txt` внутри архива.

## 🖥 Требования

- PHP 7.4+ (проверено на 8.x)
- Любой хостинг с PHP (Apache или nginx, включая бесплатные)
- Без MySQL, без крона, без composer
